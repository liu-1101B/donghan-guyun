# 音韵条目来源与近似读音规则

## 当前东汉实验字表

\`phonology_db.py\` 中的 \`EASTERN_HAN_DB\` 继续保留原有字音值和查询接口，避免本次改动改变已收录字的 IPA。现阶段它应被称为“项目东汉实验字表”，不能仅凭现有代码把全部条目归给某一位学者，也不能把 703 条记录视为已经逐字完成文献核验。

没有登记到具体文献、版本和页码的条目，状态为 \`unassessed\`，表示证据链尚未补齐，不等于已经判定条目错误。逐字核验后，将对应记录写入 \`language/provenance.py\` 的 \`LEGACY_ENTRY_PROVENANCE\`，提供可定位来源，并说明是直接转录还是按规则推导。不得猜测页码或学者归属。

## 缺字与现代拼音

字表未收录的字，默认不再自动转换为现代普通话拼音进入历史音频，而是列为缺失并从历史音频序列中跳过。用户可主动打开“允许现代拼音近似补读”；启用后，界面和结果会标记为 \`modern_pinyin_approximation\`，不得与历史重构收录值合并统计。

覆盖率以全部汉字位置为分母：已收录、近似和缺失均计入总数，避免因缺字被排除而虚高。学术来源可信度与 TTS 引擎对音段的实现能力是两项独立指标。
